
# Guía de Redes: Debian & Raspberry Pi

## 1. Ver mi dirección IP
Existen tres formas principales. La primera es la estándar actual.

| Método | Comando | Nota |
| :--- | :--- | :--- |
| **Estándar** | `ip addr show` | Muestra todo. Puedes abreviarlo como `ip a`. |
| **Resumido** | `hostname -I` | Solo te da las IPs. Ideal para un vistazo rápido. |
| **Clásico** | `ifconfig` | Requiere `sudo apt install net-tools`. Útil si vienes de la vieja escuela. |


## 2. Archivos de Configuración (El "Corazón" de la red)
**Importante:** En Debian/Raspberry hay una guerra de servicios. Debes saber cuál usa tu sistema para no editar el archivo equivocado.

### A. NetworkManager (Sistemas modernos / Desktop / Bookworm)
Los archivos **no se editan a mano**, se gestionan con comandos, pero se guardan aquí para consulta:
* **Ruta:** `/etc/NetworkManager/system-connections/` (Hay un archivo por cada red).

### B. DHCPCD (Sistemas antiguos / Lite / Bullseye)
Si tu sistema es más viejo o no tiene NetworkManager, este es el archivo maestro:
* **Ruta:** `/etc/dhcpcd.conf`
* **Sintaxis para IP Fija:**
  ```bash
  # Editar con: sudo nano /etc/dhcpcd.conf
  interface eth0
  static ip_address=192.168.1.100/24
  static routers=192.168.1.1
  static domain_name_servers=8.8.8.8 1.1.1.1
  ```

### C. El archivo de DNS (Global)
* **Ruta:** `/etc/resolv.conf`
* **Explicación:** Aquí vive la configuración de los servidores DNS (ej: `nameserver 8.8.8.8`). 
* **¡Cuidado!:** Si este archivo dice `# Generated by NetworkManager`, **no lo toques**. Cualquier cambio manual se borrará al reiniciar. Debes cambiar el DNS desde `nmcli` o `dhcpcd.conf`.


## 3. Herramientas de Manejo de Redes

### 🛠 NetworkManager (`nmcli`)
Es la herramienta más potente hoy en día.
* **Instalación:** `sudo apt update && sudo apt install network-manager`
* **Sintaxis Básica:** `nmcli [objeto] [acción]`
* **Comandos clave:**
	* `nmcli device status` -> Ver qué interfaces (wifi/cable) están activas.
	* `nmcli connection show` -> Ver nombres de perfiles guardados.
	* `sudo nmcli connection delete [nombre]` -> Borra una red que da problemas.

### 🛠 La interfaz visual (`nmtui`)
Si los comandos te lían, usa esta herramienta visual en la terminal:
```bash
sudo nmtui
```
*(Permite editar IPs, DNS y conectar a WiFi usando las flechas del teclado).*


## 4. Conectar a WiFi por CLI (Paso a Paso)

Este es el método que no falla usando **NetworkManager**:

### Paso 1: Escanear el SSID (Nombre del WiFi)
```bash
nmcli device wifi rescan      # Refresca la lista
nmcli device wifi list        # Muestra las redes cerca
```

### Paso 2: Ejecutar la conexión
**Sintaxis:** `sudo nmcli device wifi connect "NOMBRE_SSID" password "CONTRASEÑA"`
```bash
# Ejemplo real:
sudo nmcli device wifi connect "MiCasa_Fiber" password "mi_clave_segura"
```

### Paso 3: Configurar IP Estática en esa red (Opcional)
Si quieres que esa red WiFi específica siempre te dé la misma IP:
```bash
# 1. Buscas el nombre del perfil creado (suele ser el mismo SSID)
nmcli con show
# 2. Le asignas la IP fija
sudo nmcli con mod "MiCasa_Fiber" ipv4.addresses 192.168.1.55/24 ipv4.gateway 192.168.1.1 ipv4.method manual
# 3. Reinicias la conexión para que tome los cambios
sudo nmcli con up "MiCasa_Fiber"
```


## 5. Resumen de comandos de diagnóstico
Para tu Obsidian, ten estos a mano para cuando "internet no funcione":

1. `ping -c 4 8.8.8.8` -> ¿Hay conexión física al exterior?
2. `ping -c 4 google.com` -> ¿Funciona el DNS? (Si el de arriba funciona y este no, tu DNS está mal).
3. `ip route` -> ¿Quién es mi puerta de enlace (router)?
4. `journalctl -u NetworkManager -f` -> Ver en tiempo real qué errores da el WiFi al intentar conectar.
